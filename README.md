#  Rock, Paper, Scissors Game

##  Project Overview
This is a simple **Rock, Paper, Scissors** game built using **HTML, CSS, and JavaScript**. The user types in their choice — rock, paper, or scissors — and competes against a randomly generated computer selection.

When a user submits their choice, the game:

- Validates the input to ensure it is **rock**, **paper**, or **scissors**  
- Randomly generates the computer’s choice  
- Compares the user’s choice with the computer’s choice  
- Displays the result of the round (Win, Lose, or Tie)  
- Updates the score counters for:
  - Player wins  
  - Computer wins  
  - Ties  

The game also includes a **reset button** that clears all scores so the user can start fresh at any time.

## Key Concepts Demonstrated
-  DOM manipulation  
-  Input validation  
-  Conditional logic  
-  Random number generation  
-  State management with variables
